# Запуск локально

- Закомментировать backend в docker-compose.yml
- Добавить проброс портов для БД
- В .env DB_HOST указать localhost
- Перейти в папку Backend
- Запустить командой `uvicorn app.main:app --reload`
- Запустить файлы db_sync.py, init_admin.py

# Запуск в прод

- Раскомментировать все в docker-compose.yml
- Убрать раздел порты для БД
- В .env DB_HOST указать имя контейнера БД
- Запуск командой `docker compose up -d`
- Зайти внутрь контейнера `docker exec -it <container_name> /bin/sh`
- Запустить файлы db_sync.py, init_admin.py
- Выйти из контейнера командой `exit`

# Контейнеры
- Пересобрать контейнер после изменений в коде `docker compose up -d --build`
- Отключить контейнеры и стереть `docker compose down`
- Отключить контейнеры `docker compose stop`
